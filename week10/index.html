Hãy kiểm tra các thông tin quan trọng. học Thiết kế Web mà bạn cần nắm vững: 🎨 1. CSS là gì? CSS (Cascading Style Sheets) là ngôn ngữ dùng để trang trí và định kiểu cho các phần tử HTML, giúp trang web trở nên đẹp và chuyên nghiệp hơn. 📌 2. Cách nhúng CSS vào HTML Cách Cú pháp Mô tả Inline Trong thuộc tính style Áp dụng trực tiếp vào thẻ HTML Internal Trong thẻ <style> ở <head> Định dạng trong cùng một file HTML External Dùng file .css bên ngoài Cách chuyên nghiệp, dễ bảo trì Ví dụ: 👉 Inline <p style="color: red;">Chữ màu đỏ</p> 👉 Internal <head> <style> p { color: blue; } </style> </head> 👉 External <!-- HTML --> <link rel="stylesheet" href="style.css"> /* style.css */ p { color: green; } 🔠 3. Bộ chọn (Selectors) Bộ chọn Ý nghĩa Ví dụ * Chọn tất cả * { margin: 0; } element Theo tên thẻ p { color: red; } .class Theo class .box { ... } #id Theo id #main { ... } element1, element2 Nhiều thẻ cùng lúc h1, h2 { ... } element element Con trong cha div p { ... } element:hover Khi rê chuột a:hover { ... } 🎨 4. Các thuộc tính định dạng văn bản Thuộc tính Ý nghĩa Ví dụ color Màu chữ color: red; font-size Kích thước chữ font-size: 16px; font-family Font chữ font-family: Arial; text-align Căn lề (trái, phải, giữa) text-align: center; font-weight Độ đậm chữ font-weight: bold; text-decoration Gạch chân, bỏ gạch, gạch ngang... text-decoration: none; 📏 5. Kích thước & Khoảng cách Thuộc tính Mô tả width, height Chiều rộng / cao margin Khoảng cách ngoài padding Khoảng cách trong border Viền box-sizing Kiểm soát padding + border 👉 Ví dụ: .box { width: 200px; height: 100px; margin: 20px; padding: 10px; border: 1px solid black; } 📦 6. Màu sắc trong CSS Cách Ví dụ Tên màu tiếng Anh color: blue; Mã HEX color: #ff0000; Mã RGB color: rgb(255, 0, 0); Mã RGBA (có độ mờ) color: rgba(0,0,0,0.5); 📐 7. Vị trí phần tử position: static; /* mặc định */ position: relative; /* tương đối */ position: absolute; /* tuyệt đối */ position: fixed; /* cố định màn hình */ position: sticky; /* dính khi cuộn */ 🧱 8. Hiển thị & Ẩn phần tử display: block; /* hiển thị theo khối */ display: inline; /* hiển thị theo dòng */ display: none; /* ẩn */ visibility: hidden; /* ẩn nhưng vẫn chiếm chỗ */ 🌐 9. Layout cơ bản với Flexbox .container { display: flex; justify-content: center; /* căn giữa ngang */ align-items: center; /* căn giữa dọc */ } 🎞️ 10. Hiệu ứng & chuyển động transition: all 0.5s; :hover { background-color: yellow; } 📁 11. Media Queries (Responsive Web) @media (max-width: 768px) { body { background-color: lightgray; } } ✅ 12. Một số thuộc tính CSS quan trọng khác Thuộc tính Mô tả overflow Xử lý tràn nội dung z-index Thứ tự lớp chồng opacity Độ trong suốt cursor Kiểu con trỏ background Nền (màu, ảnh...) 📘 13.
